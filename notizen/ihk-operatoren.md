# Operatoren


| Operator            | Erwartete Leistung                                                                                                                                               |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| nennen / angeben    | Geforderte Begriffe, Fakten oder Beispiele ohne Erläuterung aufzählen.                                                                                           |
| benennen            | Einen Sachverhalt, Bestandteil oder Fachbegriff eindeutig identifizieren und bezeichnen.                                                                         |
| beschreiben         | Merkmale, Eigenschaften, Zustände oder Abläufe sachlich und nachvollziehbar darstellen.                                                                          |
| darstellen          | Einen Sachverhalt strukturiert wiedergeben, gegebenenfalls mithilfe einer Tabelle oder eines Diagramms.                                                          |
| erklären            | Einen Sachverhalt verständlich machen und Ursachen, Wirkungen oder Funktionsweisen aufzeigen.                                                                    |
| erläutern           | Einen Sachverhalt erklären und durch zusätzliche Informationen, Beispiele oder Zusammenhänge verdeutlichen.                                                      |
| begründen           | Eine Aussage, Entscheidung oder Vorgehensweise durch nachvollziehbare fachliche Argumente stützen.                                                               |
| vergleichen         | Gemeinsamkeiten und Unterschiede anhand geeigneter Kriterien systematisch herausarbeiten.                                                                        |
| unterscheiden       | Wesentliche Abgrenzungsmerkmale zwischen Begriffen oder Sachverhalten herausstellen.                                                                             |
| analysieren         | Einen Sachverhalt systematisch untersuchen, relevante Bestandteile und Zusammenhänge erkennen und Ergebnisse ableiten.                                           |
| beurteilen          | Einen Sachverhalt anhand fachlicher Kriterien bewerten, Argumente gewichten und zu einem begründeten Urteil gelangen.                                            |
| bewerten            | Einen Sachverhalt anhand festgelegter oder geeigneter Maßstäbe hinsichtlich seiner Qualität, Eignung oder seines Nutzens einschätzen und das Ergebnis begründen. |
| prüfen / überprüfen | Feststellen, ob vorgegebene Anforderungen, Bedingungen oder Kriterien erfüllt sind.                                                                              |
| ermitteln           | Ein gesuchtes Ergebnis aus gegebenen Informationen durch ein geeignetes Verfahren bestimmen.                                                                     |
| berechnen           | Ein numerisches Ergebnis anhand mathematischer Verfahren bestimmen und den Rechenweg gegebenenfalls dokumentieren.                                               |
| zuordnen            | Vorgegebene Elemente anhand ihrer Eigenschaften passenden Kategorien oder anderen Elementen zuweisen.                                                            |
| ergänzen            | Eine unvollständige Darstellung entsprechend den Vorgaben vervollständigen.                                                                                      |
| skizzieren          | Wesentliche Merkmale oder Strukturen vereinfacht und übersichtlich darstellen.                                                                                   |
| zeichnen            | Eine grafische Darstellung entsprechend den fachlichen Vorgaben und gegebenenfalls einer festgelegten Notation anfertigen.                                       |
| erstellen           | Ein gefordertes Arbeitsergebnis entsprechend den Anforderungen anfertigen, beispielsweise ein Diagramm, eine SQL-Abfrage oder einen Algorithmus.                 |
| entwickeln          | Eine eigenständige, fachlich begründete Lösung für eine Problemstellung konzipieren und entsprechend den Anforderungen ausarbeiten.                              |
| implementieren      | Einen vorgegebenen Entwurf oder eine beschriebene Funktionalität in ausführbaren Code oder geforderten Pseudocode umsetzen.                                      |
| optimieren          | Eine bestehende Lösung anhand bestimmter Kriterien gezielt verbessern, ohne wesentliche Anforderungen zu verletzen.
