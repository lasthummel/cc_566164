# Aufgabe 'BPMN'

Ein Supportprozess wird von folgenden Rollen bearbeitet:

- Kunde
- Supportmitarbeiter
- Fachabteilung

Modellieren Sie in BPMN den vereinfachten Prozess:

1. Kunde meldet Problem.
2. Supportmitarbeiter nimmt Anfrage auf.
3. Supportmitarbeiter prüft, ob das Problem selbst gelöst werden kann.
4. Falls ja: Lösung wird an den Kunden übermittelt.
5. Falls nein: Anfrage wird an die Fachabteilung weitergeleitet.
6. Fachabteilung bearbeitet die Anfrage.
7. Lösung wird an den Kunden übermittelt.
8. Prozess endet.

Verwenden Sie mindestens zwei Lanes.
