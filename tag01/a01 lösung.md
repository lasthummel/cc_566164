### 1.2 Aussagen korrigieren

Korrigieren Sie jede Aussage in ein bis zwei fachlich präzisen Sätzen.

a) „GitHub ist das Versionsverwaltungssystem; Git ist nur die Kommandozeile dazu.“

Git ist das verteilte Versionsverwaltungssystem. GitHub ist eine Hosting- und Kollaborationsplattform für Git-Repositories; 

b) „Eine IDE kompiliert den Code selbst und ersetzt daher Compiler und Laufzeitumgebung.“

 Eine IDE integriert Entwicklungsfunktionen und kann Compiler, Debugger oder Laufzeitumgebungen aufrufen. Sie ist nicht mit diesen Komponenten gleichzusetzen und ersetzt sie fachlich nicht.

c) „Wenn alle Entwickler eine Bibliothek manuell herunterladen, ist der Build automatisch reproduzierbar.“

Manuelle Downloads garantieren keine identischen Versionen und keine nachvollziehbare Auflösung transitiver Abhängigkeiten. Deklarierte, versionierte Abhängigkeiten und ein reproduzierbarer Build-Prozess reduzieren diese Risiken.

d) „Ein Commit ist dasselbe wie ein Backup.“

Ein versionierter Snapshot im Repository.
Ein Commit dokumentiert einen Versionsstand in der Repository-Historie. Ein Backup ist eine gesonderte Sicherung gegen Verlust oder Beschädigung; ein Commit schützt nicht gegen den Verlust des einzigen Repositorys.
